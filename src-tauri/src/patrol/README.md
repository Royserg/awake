# Native cursor patrolling

`model.rs` defines strict wire DTOs, checked decimal counters and canonical half-open display geometry. `controller.rs` is a pure setup/run state machine; `engine.rs` samples eased motion through injectable clock/position ports. `overlays.rs` and `mod.rs` coordinate effects on the main thread. Windows WebView2 construction runs on a separate thread as required by Tauri; native placement, mapping and visibility return to the main actor. Cancel/rebuild waits for construction to finish, so late windows cannot reappear after cleanup. `platform` contains all unsafe native boundaries and private display identities.

A setup keeps a draft separate from the last accepted route. Start freezes its route/layout pair and registered source membership, waits at most two seconds for every source to drain and acknowledge its edits, then arms. Changed drafts, incomplete sources, late edits and stale confirmations abort admission. The native observer must publish a fresh lease for the reserved generation. Only after native preflight, Awake activation, overlay removal and final checks does the controller commit Running. Failed starts retain the draft and actual Awake state.

Exactly one movement worker exists. It moves toward point 1, then follows addition order and loops; if already at point 1 it pauses immediately. Travel lasts nominally 500 ms with smoothstep easing and at most 60 samples/second. No sample is emitted in desktop gaps. The full configured pause starts only after the endpoint call returns successfully. No catch-up bursts or cursor restoration occur.

Cancellation stores the first reason and wakes the worker; a later display change independently latches review. Stopping retains the run until a synchronous native call finishes and the worker records acknowledgment. Observer/availability leases expire at 100 ms inclusively, including during pauses. A wake gap over 150 ms cancels before emitting. Before-call checks sample time after native prechecks, preventing a slow OS query from using stale authorization.

The emission gate reserves a call without holding its mutex across native code. The main actor receives work through an off-main dispatcher so synchronous native callbacks cannot re-enter its mutex. Tray refresh runs after releasing that mutex; setup events publish only when the version changes. The main actor closes admission for Awake/timer operations and waits asynchronously for emission/stop acknowledgment. It never holds AppState while awaiting native work. Off cancels before attempting NoSleep release. Failed release leaves actual Awake active and movement stopped. Timers use elapsed Duration arithmetic, including u64::MAX milliseconds.

macOS uses an owned passive session event tap/run loop, event-free cursor warp, public session/sleep notifications and main-thread secure-input queries. Optional input-access symbols are resolved at runtime; permissions are requested only explicitly. Windows uses a hidden top-level Raw Input window after Tao's raw-device capture is disabled, checks registration ownership, preserves normal webview input, and observes desktop/session/power/display changes. DPI entry points are resolved at runtime. Every positioning call checks confinement; successful calls require matching readback. Neither backend changes another application's confinement.

Native display tokens survive established continuous identities. Removed/unknown attachments receive new tokens. macOS callbacks retire the affected native display; generic Windows display broadcasts conservatively retire all tokens because continuous attachment cannot be proved from the broadcast. Retained points then require re-placement or removal before review/Start. This intentionally favors explicit review over silently reusing an uncertain attachment.

Normal setup close, failed start, stop and exit have explicit cleanup paths. Old session epochs and disabled routers cannot affect a later run. Callback storage stays alive until native deregistration and thread completion; failed cleanup blocks new setup/Start. Process-plugin exit/restart keeps the existing namespace/ACL and coordinates a two-second grace. An installer-owned reserved Tauri restart cannot be deferred, so its exit event immediately cancels native movement before process termination.

`tests.rs` uses fake time/input/position ports and pure controller transitions on every desktop target; these tests never create native windows or move the pointer. The existing AppState tests separately exercise the macOS sleep inhibitor. Run the Rust checks plus `pnpm test:patrol`; native behavioral acceptance remains documented separately in `docs/cursor-patrolling/validation.md`.
